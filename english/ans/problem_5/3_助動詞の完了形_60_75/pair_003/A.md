## 詳細な解説

### A. あなたはそんなに早く起きる必要はなかったのに。

**完成した英文**:
You **needn't** **have** **gotten** **up** so early.

**解答**:
- (a): 1 - needn't
- (b): 2 - have
- (c): 3 - gotten
- (d): 4 - up
- **不要語**: 5 - need

**Next Stage参照**: No. 68 - needn't have done「…する必要はなかったのに（実際はした）」

**解説**:

1. **文の骨格**:
   「起きる必要はなかったのに」は needn't have gotten up で表現します。

2. **語法のポイント**:
   - `needn't have + 過去分詞`：不必要だったのに実際にはしてしまった
   - 「実際には早く起きたが、起きる必要はなかった」という後悔・徒労
   - get up「起きる」の過去分詞は gotten（アメリカ英語）または got

3. **なぜ need が不要か**:
   needn't have done の形で表現するため、原形の need は使いません。

4. **覚えるべき形**:
   `needn't have done「…する必要はなかったのに（実際はした）」`

### B. 彼にもっと早く電話すべきだったのに。

**完成した英文**:
You **had** **better** **have** **called** him sooner.

**解答**:
- (a): 3 - had
- (b): 1 - better
- (c): 5 - have
- (d): 2 - called
- **不要語**: 6 - should

**Next Stage参照**: No. 56-57 関連 - had better have done「…すべきだったのに」

**解説**:

1. **文の骨格**:
   「電話すべきだったのに」は had better have called で表現します。

2. **語法のポイント**:
   - `had better have + 過去分詞`：過去の行為への後悔・非難
   - 「実際にはそうしなかったが、そうすべきだった」という意味
   - had better do「〜した方がよい」の完了形

3. **なぜ should が不要か**:
   had better have done の形で表現するため、should は使いません。should have done でも意味は通じますが、この問題では had better have done を作ります。

4. **覚えるべき形**:
   `had better have done「…すべきだったのに（実際はしなかった）」`

### C. パーティーに行けばよかったのに。

**完成した英文**:
I **would** **rather** **have** **gone** **to** the party.

**解答**:
- (a): 2 - would
- (b): 1 - rather
- (c): 5 - have
- (d): 4 - gone
- (e): 3 - to
- **不要語**: 6 - go

**Next Stage参照**: No. 54-55 関連 - would rather have done「…すればよかった」

**解説**:

1. **文の骨格**:
   「行けばよかった」は would rather have gone で表現します。

2. **語法のポイント**:
   - `would rather have + 過去分詞`：過去の行為への後悔
   - 「実際には行かなかったが、行けばよかった」という願望
   - would rather do「むしろ〜したい」の完了形
   - go to the party「パーティーに行く」

3. **なぜ go が不要か**:
   would rather have の後は過去分詞が来るので、原形の go ではなく gone が正しいです。

4. **覚えるべき形**:
   `would rather have done「…すればよかった（実際はしなかった）」`

### D. 彼女にもう一度会いたかったのに。

**完成した英文**:
I **should** **like** **to** **have** **seen** her once more.

**解答**:
- (a): 3 - should
- (b): 1 - like
- (c): 5 - to
- (d): 6 - have
- (e): 2 - seen
- **不要語**: 4 - see

**Next Stage参照**: No. 64-67 関連 - should like to have done「…したかったのに」

**解説**:

1. **文の骨格**:
   「会いたかったのに」は should like to have seen で表現します。

2. **語法のポイント**:
   - `should like to have + 過去分詞`：実現しなかった願望
   - 「実際には会えなかったが、会いたかった」という意味
   - 主にイギリス英語で使われる表現
   - would like to have done でも同様の意味

3. **なぜ see が不要か**:
   should like to have の後は過去分詞が来るので、原形の see ではなく seen が正しいです。

4. **覚えるべき形**:
   `should like to have done「…したかったのに（実際はできなかった）」`
