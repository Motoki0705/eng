# 重要構文 pair_003 - 習得すべき知識（整序英作文）

## 📚 このペアで学ぶ文法事項

### 1. too ... to do (No. 123関連)

```
too + 形容詞/副詞 + to do「〜すぎて...できない」
```

**例**: She is **too young to** make such a decision.
（彼女は若すぎてそのような決断ができない）

**例**: This coffee is **too hot to** drink.
（このコーヒーは熱すぎて飲めない）

> 💡 **意味上の主語を加える場合**
> ```
> too + 形容詞 + for A + to do「Aにとって〜すぎて...できない」
> ```
> **例**: The book is too difficult **for me** to understand.
> （その本は私には難しすぎて理解できない）

> 🔄 **so ... that との書き換え**
> ```
> She is too young to make such a decision.
> = She is so young that she can't make such a decision.
> ```
> too ... to は「否定」が隠れていることを忘れずに！

---

### 2. ... times as + 原級 + as A (No. 181)

```
... times as + 原級 + as A「Aの…倍～」
```

**例**: This room is **three times as large as** that one.
（この部屋はあの部屋の3倍の広さだ）

**例**: He earns **twice as much as** I do.
（彼は私の2倍稼いでいる）

> 💡 **倍数表現のバリエーション**
> - twice as + 原級 + as A「Aの2倍～」
> - half as + 原級 + as A「Aの半分～」
> - three times the size of A「Aの3倍の大きさ」（名詞を使った表現）

---

### 3. not so much A as B (No. 192関連)

```
not so much A as B「AというよりはむしろB」
```

**例**: He is **not so much** a scholar **as** a journalist.
（彼は学者というよりはむしろジャーナリストだ）

> 🔄 **同意表現**
> ```
> not so much A as B = B rather than A
> ```
> **例**: He is a journalist rather than a scholar.

> ⚠️ **混同注意！**
> - not so much A as B「AというよりはむしろB」
> - not so much as do「…さえしない」← これは別の表現！

---

### 4. the + 比較級 ..., the + 比較級 〜 (No. 192)

```
the + 比較級 ..., the + 比較級 〜「…すればするほど、ますます〜」
```

**例**: **The more** you study, **the more** you learn.
（勉強すればするほど、より多くのことを学ぶ）

**例**: **The older** he gets, **the wiser** he becomes.
（年を取れば取るほど、彼はより賢くなる）

> 💡 **語順に注意**
> 比較級が形容詞＋名詞を修飾する場合：
> ```
> The more books you read, the more knowledge you gain.
> ```
> 「the + 比較級 + 名詞」の語順になる！

---

### 5. unless ... / if ... not ... (No. 354, 355関連)

```
unless ...「…しない限り」≒ if ... not ...
```

**例**: **Unless** you study hard, you won't pass the exam.
（一生懸命勉強しない限り、試験に合格しないだろう）

= If you **don't** study hard, you won't pass the exam.

> ⚠️ **unlessとif ... notの違い**
> unlessは条件の締めつけが強く、すべてのif ... notがunlessに書きかえられるわけではない。
> 選択肢にif ... notとunlessが並んでいれば、if ... notの形を選ぶのが無難。

---

### 6. without so much as doing (No. 186関連)

```
without so much as doing「…さえしないで」
```

**例**: He left **without so much as saying** good-bye.
（彼はさよならさえ言わずに去った）

> 💡 **関連表現**
> - not so much as do「…さえしない」
> **例**: He did **not so much as** apologize.
> （彼は謝りさえしなかった）

---

### 7. 動詞を含むイディオム (No. 814, 815)

```
lay off A / lay A off「Aを一時解雇する」
break off A「A（関係など）を絶つ／A（交渉など）を打ち切る」
```

**例**: The company **laid off** many workers.
（その会社は多くの労働者を一時解雇した）

**例**: We should not **break off** relations with neighboring countries.
（私たちは近隣諸国との関係を絶つべきではない）

> 💡 **句動詞のポイント**
> - lay off は「一時的な解雇」を意味する
> - break off は「関係・交渉を断つ」の意味
> - 目的語が代名詞の場合は lay it off のように間に入れる

---

## 📝 整序問題のコツ

1. **まず日本語訳から構文を特定する**
   - 「〜すぎて…できない」→ too ... to do
   - 「〜倍の」→ ... times as + 原級 + as
   - 「AというよりB」→ not so much A as B

2. **不要語を見極める**
   - 似た意味の語（so/too, if/unless）があれば、どちらかが不要
   - 構文に合わない語を除外

3. **語順のパターンを覚える**
   - too + 形容詞 + to do
   - ... times + as + 形容詞 + as
   - the + 比較級 + S + V, the + 比較級 + S + V
