# 動詞の語法 pair_005 - 習得すべき知識

## 📚 このペアで学ぶ文法事項

### 1. 動名詞のみを目的語にとる動詞

#### enjoy doing (No. 516)
```
enjoy doing「〜することを楽しむ」
```

**例**: We **enjoyed watching** the movie.

> 🎉 **enjoy の後は必ず -ing！**
> enjoy は「楽しんでいる最中」の感覚があるので、進行中を表す -ing 形と相性が良い。to do は ✕。

---

#### finish doing (No. 518)
```
finish doing「〜し終える」
```

**例**: Have you **finished reading** the book?

> ✅ **finish も -ing 専用！**
> finish は「すでに進行中の行為を終える」意味なので、動名詞をとる。

---

#### deny doing (No. 521)
```
deny doing「〜したことを否定する」
```

**例**: He **denied stealing** the money.

> 🚫 **否定する内容は過去の行為**
> deny の後には「すでに起こった（とされる）行為」がくるので、動名詞がふさわしい。
> 完了動名詞 deny having done の形もよく出る！

---

#### regret doing (No. 533)
```
regret doing「〜したことを後悔する」
```

**例**: I **regret saying** those words.

> 😢 **過去の行為を後悔**
> regret doing = 過去にしたことを後悔
> regret to do = 残念ながら〜する（これからの行為）

| 形 | 時制 | 意味 |
|-----|-----|-----|
| regret doing | 過去 | 〜したことを後悔する |
| regret to do | 未来 | 残念ながら〜する |

**例**: I regret to inform you that...（残念ながらお知らせしますが...）

---

### 2. 不定詞のみを目的語にとる動詞

#### expect to do (No. 524)
```
expect to do「〜するつもりである／〜することを予期する」
```

**例**: I **expect to graduate** next year.

> 🎯 **未来志向の動詞は to do！**
> expect, hope, decide, plan, want, promise...
> これらは全て「これからのこと」を表すので to 不定詞と相性が良い。

---

#### hope to do (No. 526)
```
hope to do「〜することを望む」
```

**例**: I **hope to see** you again.

> 💭 **hope + doing は ✕**
> hope は未来の願望を表すので、必ず to 不定詞。
> ただし hope that S + V の形は可能。

---

#### offer to do (No. 527)
```
offer to do「〜することを申し出る」
```

**例**: She **offered to help** me.

> 🤝 **申し出は未来の行為**
> 「これから〜しましょうか」と申し出るので to do。

---

#### pretend to do (No. 528)
```
pretend to do「〜するふりをする」
```

**例**: He **pretended to be** asleep.

> 🎭 **ふりをする = これからの状態を装う**
> pretend は to 不定詞をとる。

---

## ✅ 動名詞 vs 不定詞 まとめ

### 動名詞のみをとる動詞（MEGAFEPS）
| 動詞 | 意味 |
|------|------|
| **M**ind | 気にする |
| **E**njoy | 楽しむ |
| **G**ive up | あきらめる |
| **A**void | 避ける |
| **F**inish | 終える |
| **E**scape | 逃れる |
| **P**ut off | 延期する |
| **S**top | やめる |

+ deny, consider, admit, suggest なども重要！

### 不定詞のみをとる動詞
| 動詞 | 意味 |
|------|------|
| decide | 決める |
| hope | 望む |
| expect | 予期する |
| offer | 申し出る |
| pretend | ふりをする |
| refuse | 断る |
| promise | 約束する |
| want | 望む |

> 💡 **覚え方のコツ**
> - 動名詞 = 過去・進行中・習慣的な行為
> - 不定詞 = 未来・これからの行為
