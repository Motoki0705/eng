# 仮定法 pair_002 - 習得すべき知識

## 📚 このペアで学ぶ文法事項

### 1. 仮定法過去−主節の形 (No. 77)

#### 仮定法過去の主節
```
If S + 過去形 ..., S' + would/could/might + 原形 ...
```

**ポイント**: 主節には **would / could / might / should + 動詞の原形** を使う

**例**: If my sister **were** here, she **would advise** me on what to do.
（もし姉がここにいれば、何をすべきか私にアドバイスしてくれるのに）

> 💡 **主節の助動詞の使い分け**
> - **would**: 「〜だろう」（推量）
> - **could**: 「〜できるだろう」（能力・可能）
> - **might**: 「〜かもしれない」（可能性）
> - **should**: 1人称（I, we）で「〜だろう」（主にイギリス英語）

---

### 2. 仮定法過去完了−従節の形 (No. 79)

#### 仮定法過去完了の従節
```
If S + had + 過去分詞 ..., S' + would/could/might + have + 過去分詞 ...
```

**ポイント**: 従節には **had + 過去分詞（過去完了形）** を使う

**例**: If I **had had** more time then, I could have checked my report again.
（もしあのときもっと時間があったら、レポートをもう一度チェックできたのに）

> ⚠️ **had had に注意！**
> have の過去完了形は had had。「持っていたなら」は If I had had ... となる。入試でよく出題されるパターン！

---

### 3. 仮定法過去・過去完了の併用形 (No. 81)

#### 従節と主節で時制が異なる場合
```
If S + had done (過去) ..., S' + would + 原形 (現在) ...
「もし（あのとき）〜だったら、（今）...だろうに」
```

**例**: If I **had been** told so **then**, I **would be** happier **now**.
（もしあのときそう言われていたら、今もっと幸せだろうに）

> 🔑 **時制のヒントを見逃すな！**
> - 従節: **then, at that time, yesterday** など → 過去の仮定 → 仮定法過去完了
> - 主節: **now, today** など → 現在の推量 → 仮定法過去
> 
> 副詞に注目することが正解への近道！

---

### 4. If S were to do ... (No. 83)

#### 実現可能性の低い未来の仮定
```
If S were to do ..., S' + would/could/might + 原形 ...
「もし（万一）Sが〜するとしたら、...だろう」
```

**例**: Even if the sun **were to rise** in the west, he would not change his mind.
（たとえ太陽が西から昇るとしても、彼は考えを変えないだろう）

> 🌅 **あり得ないことの仮定**
> If S were to do ... は、実現の可能性がほとんどない仮定や、空想的な仮定に使われる。「太陽が西から昇る」「地球が止まる」など、現実にはあり得ないことを仮定するときに最適！

---

### 5. S wish + 仮定法過去完了 (No. 86)

#### 過去の事実と反対の願望
```
S wish + S' + had + 過去分詞
「〜だったらよかったのに（と思う）」
```

**例**: I wish I **had had** enough money to buy the house around this time last year.
（去年の今頃、その家を買うのに十分なお金があったらよかったのに）

> ⏰ **時制の目印**
> - last year, at that time, then などの**過去を示す語句**がある → **仮定法過去完了**
> - now, today などの**現在を示す語句**がある → **仮定法過去**

---

### 6. If only + 仮定法 (No. 88)

#### 強い願望を表す
```
If only + S + 過去形 ... !（現在の願望）
If only + S + had done ... !（過去の願望）
「...でさえあれば！」「...だったらなあ！」
```

**例**: If **only** there were forty-eight hours in a day!
（一日が48時間であればいいのに！）

> 💫 **I wish と If only の違い**
> | | I wish ... | If only ... ! |
> |---|---|---|
> | 意味 | 〜であればいいのに | 〜でさえあれば！ |
> | ニュアンス | 穏やかな願望 | 強い願望・感嘆 |
> | 文末 | ピリオド | 感嘆符(!)が多い |
> 
> If only は I wish の**強調版**と覚えよう！

---

### 7. as if + 仮定法過去完了 (No. 91)

#### 過去の事実と異なる様態
```
S + V + as if + S' + had + 過去分詞
「まるでS'が〜したかのように」
```

**例**: He talks as if he **knew** everything about Australia.（仮定法過去）
（まるでオーストラリアのことを何でも知っているかのように話す）

**例**: She looked as if she **had seen** a ghost.（仮定法過去完了）
（まるで幽霊を見たかのような顔をしていた）

> 🎭 **as if / as though の時制**
> - 主節と**同じ時**のこと → **仮定法過去**
> - 主節より**前の時**のこと → **仮定法過去完了**
> 
> He talks (現在) as if he **knew** (主節と同時) everything.
> He talked (過去) as if he **had known** (主節より前) everything.

---

### 8. but for A (No. 94)

#### 「もしAがなければ / なかったら」
```
But for A, S + would + 原形 ...（現在の仮定）
But for A, S + would have done ...（過去の仮定）
```

**同義表現**:
- **without A**
- **if it were not for A**（現在）
- **if it had not been for A**（過去）

**例**: **But for** his recommendation, I would not have got a promotion.
（彼の推薦がなかったら、私は昇進しなかっただろう）

> 📝 **書き換えマスター**
> | 表現 | 現在の仮定 | 過去の仮定 |
> |-----|-----------|-----------|
> | but for A | ○ | ○ |
> | without A | ○ | ○ |
> | if it were not for A | ○ | × |
> | if it had not been for A | × | ○ |
> 
> but for / without は時制に関係なく使える万能選手！
