# 分詞 pair_003 - 習得すべき知識

## 📚 このペアで学ぶ文法事項

### 1. hear A doing / hear A done (No. 164, 165)

#### hear A doing「Aが〜しているのを聞く」
```
hear + A + doing「Aが〜しているのを聞く」
```

**例**: I **heard** him **singing** in the shower.
（彼がシャワーで歌っているのを聞いた）

> 👂 **現在分詞は「途中の一場面」**
> heard him singing = 歌っている最中の一部分を聞いた
> 知覚動詞（hear, see, feel など）+ O + doing の形は、動作の進行中を表します。

#### hear A done「Aが〜されるのを聞く」
```
hear + A + done「Aが〜されるのを聞く」
```

**例**: I **heard** my name **called**.
（自分の名前が呼ばれるのを聞いた）

> 🔄 **受動関係なら過去分詞！**
> my name と call の関係 → 名前が「呼ばれる」（受動）
> him と sing の関係 → 彼が「歌う」（能動）
> 
> この能動・受動の判断が分詞選択の鍵！

### 2. make oneself understood / heard (No. 167)

```
make oneself understood「自分の言うことを相手にわからせる」
make oneself heard「自分の声を届けさせる」
```

**例**: I couldn't **make myself understood** in French.
（フランス語で自分の言いたいことを伝えられなかった）

**例**: The room was so noisy I couldn't **make myself heard**.
（部屋がうるさすぎて、自分の声が届かなかった）

> 🗣️ **「自分を〜された状態にする」**
> | 表現 | 直訳 | 意味 |
> |-----|-----|-----|
> | make oneself understood | 自分を理解された状態にする | 意思を伝える |
> | make oneself heard | 自分を聞かれた状態にする | 声を届ける |
> 
> SVOC構文で、O（oneself）とC（過去分詞）が受動関係！

---

### 3. 分詞を否定する語 (No. 170)

```
Not doing ...「〜しないで」
Not having done ...「〜しなかったので」
```

**例**: **Not knowing** what to say, I kept silent.
（何を言うべきかわからなかったので、黙っていた）

**例**: **Not having** been there before, I got lost.
（以前そこに行ったことがなかったので、道に迷った）

> ⚡ **否定語は分詞の「直前」に置く！**
> ```
> ✓ Not knowing ...（正しい）
> ✗ Knowing not ...（誤り）
> ```
> 動名詞の否定と同じルール。否定語（not, never）は必ず分詞の前！

---

### 4. 独立分詞構文 (No. 174)

```
名詞/代名詞 + doing/done, S + V ...
（分詞の主語が文の主語と異なる場合、分詞の前に主語を明示）
```

**例**: **All things considered**, this is the best choice.
（すべてを考慮すると、これが最善の選択だ）

**例**: **The weather permitting**, we'll go on a picnic.
（天気が許せば、ピクニックに行こう）

> 📌 **主語が違うなら明示する！**
> 通常の分詞構文：主節と分詞の主語が一致
> 独立分詞構文：主語が異なる → 分詞の前に主語を置く
> 
> 特に頻出の慣用表現：
> - All things considered「すべてを考慮すると」
> - Weather permitting「天気が許せば」
> - Other things being equal「他の条件が同じなら」

---

### 5. 分詞構文の強調形 as S do (No. 175)

```
Doing as S do, S + V ...
（分詞を強調するため、現在分詞の直後に as S do を置く）
```

**例**: **Standing as it does** on a hill, the hotel commands a fine view.
（丘の上に立っているので、そのホテルからは素晴らしい景色が見える）

**例**: **Living as I do** in the countryside, I rarely go to concerts.
（田舎に住んでいるので、コンサートに行くことはめったにない）

> 🔍 **「〜しているので」を強調！**
> | 基本形 | 強調形 |
> |-------|--------|
> | Standing on a hill, ... | Standing **as it does** on a hill, ... |
> | Living in Tokyo, ... | Living **as I do** in Tokyo, ... |
> 
> as S do の S は文の主語に一致させる。do は時制に合わせて does / did に変化。

---

### 6. 慣用的分詞構文 (No. 176)

| 表現 | 意味 |
|-----|-----|
| generally speaking | 一般的に言えば |
| frankly speaking | 率直に言えば |
| strictly speaking | 厳密に言えば |
| roughly speaking | 大まかに言えば |
| judging from A | Aから判断すると |
| speaking of A | Aと言えば |
| considering A | Aを考慮すると |
| talking of A | Aと言えば |

**例**: **Generally speaking**, Japanese people are hardworking.
（一般的に言えば、日本人は勤勉だ）

**例**: **Judging from** his appearance, he seems to be wealthy.
（外見から判断すると、彼は裕福そうだ）

> 📝 **イディオムとして丸暗記！**
> これらは分詞構文の主語と文の主語が一致しなくても許容される特殊な表現。
> 「懸垂分詞」とも呼ばれるが、これらの慣用表現は文法的に正しいとされる。

### 7. with A doing の付帯状況 (No. 178)

```
with + A + doing「Aが〜しながら」
with + A + done「Aが〜された状態で」
```

**例**: She sat **with her baby sleeping** in her arms.
（赤ちゃんを腕に抱いて眠らせながら座っていた）

**例**: He spoke **with his eyes closed**.
（目を閉じて話した）

> 🎬 **付帯状況を映像的に描写！**
> | A と分詞の関係 | 使う分詞 | 例 |
> |---------------|---------|-----|
> | 能動関係（Aが〜する） | doing | with the engine running |
> | 受動関係（Aが〜される） | done | with the door locked |
> 
> 「with + A + 形容詞/前置詞句/副詞」の形もあります：
> - with one's mouth full「口をいっぱいにして」
> - with a pen in one's hand「手にペンを持って」
> - with one's hat on「帽子をかぶったまま」
