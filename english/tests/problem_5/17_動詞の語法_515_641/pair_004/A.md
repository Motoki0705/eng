I've ( a ) ( b ) ( c ) ( d ) ( e ) ( f ) today.

2. this report
3. to get
4. done
5. finish
6. finished
7. do

2. her
3. that
4. she
5. exercise
6. to exercise
7. exercises

4. postponed
5. be postponed
6. postpone
7. should
