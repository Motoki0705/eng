# 敬語から主語を特定する - 古文読解の必須テクニック

## 📌 基本情報

古文では主語が省略されることが多い。**敬語の種類**から主語を特定することが、古文読解の基本テクニック。

---

## 🎯 敬語と主語の関係

### 基本ルール

| 敬語の種類 | 主語 | 例 |
|------------|------|-----|
| **尊敬語**がある | 身分の**高い**人 | 帝のたまふ（帝がおっしゃる） |
| **謙譲語**がある | 身分の**低い**人 | 翁申す（翁が申し上げる） |
| **敬語なし** | 身分の**低い**人・一般人 | 男言ふ（男が言う） |

---

## 🔍 識別フローチャート

```
動詞を発見
    ↓
敬語が使われているか確認
    ↓
┌─────────────────┬─────────────────┬─────────────────┐
│ 尊敬語          │ 謙譲語           │ 敬語なし         │
│      ↓         │      ↓          │      ↓          │
│ 主語は         │ 主語は          │ 主語は          │
│ 身分の高い人   │ 身分の低い人     │ 一般人・身分の低い人 │
└─────────────────┴─────────────────┴─────────────────┘
```

## 📊 具体例で理解する

### 例文1：尊敬語から主語を特定

> 帝、「いかなることぞ」と**仰せ**らる。

- 「仰せ」＝「言ふ」の尊敬語
- 尊敬語 → 主語は身分の高い人
- → **主語は「帝」**

### 例文2：謙譲語から主語を特定

> 翁、帝に「かくなむ」と**申す**。

- 「申す」＝「言ふ」の謙譲語
- 謙譲語 → 主語は身分の低い人
- → **主語は「翁」**

### 例文3：敬語の切り替えで主語の変化を見抜く

> 帝**仰せ**らるれば、翁**申す**。

- 「仰せ」＝尊敬語 → 主語は帝
- 「申す」＝謙譲語 → 主語は翁
- → **主語が「帝」から「翁」に変わった**

## 📝 二方面への敬語

### 地の文で二つの敬語が重なる場合

| パターン | 例 | 敬意の方向 |
|----------|-----|-----------|
| 謙譲語＋尊敬語 | 見**奉り給ふ** | 作者→動作の受け手、作者→動作主 |
| 尊敬語＋尊敬語 | 見**させ給ふ** | 作者→動作主（二重敬語） |

### 例文

> 中宮、帝を見**奉り給ふ**。

- 「奉り」＝謙譲語 → 動作の受け手（帝）への敬意
- 「給ふ」＝尊敬語 → 動作主（中宮）への敬意
- 主語は中宮、帝を見ている

---

## 💡 会話文と地の文

### 敬意の主体が変わる

| 文の種類 | 敬意の主体 |
|----------|-----------|
| **地の文** | 作者 |
| **会話文** | 話し手（登場人物） |

### 例文

> 翁言ふ、「帝**おはしまし**ぬ」と。

- 地の文「翁言ふ」→ 敬語なし → 作者は翁に敬意なし
- 会話文「帝おはしまし」→ 尊敬語 → 翁が帝に敬意

---

## 📝 練習問題

### 問題1
次の文の主語を特定せよ。

1. 源氏の君、「いかが」と**のたまふ**。
2. 女房、君に**聞こえ**けり。
3. 男、物**言ふ**。
4. 中宮**おはしまし**て、女房に**仰せ給ふ**。

### 解答
1. **源氏の君**（「のたまふ」＝尊敬語）
2. **女房**（「聞こゆ」＝謙譲語、「君」は動作の受け手）
3. **男**（敬語なし）
4. 前半：**中宮**（「おはします」＝尊敬語）、後半：**中宮**（「仰せ給ふ」＝尊敬語）

---

## 💡 福岡大学での出題ポイント

- 「この文の主語は誰か」という問題は頻出
- 敬語の種類を見分ければ**主語を特定**できる
- **接続助詞「て」「ば」**で主語が変わることにも注意
- 会話文と地の文で**敬意の主体が変わる**ことを意識

---

## ⚠️ 主語が変わるサイン

### 接続助詞に注意

| 接続助詞 | 主語の変化 |
|----------|-----------|
| **て** | 変わる場合が多い |
| **ば** | 変わる場合が多い |
| **つつ** | 変わらない |
| **ながら** | 変わらない |

> 帝**仰せられ**て、翁**申す**。
> （帝がおっしゃって、翁が申し上げる。）

→ 「て」で主語が「帝」→「翁」に変化
