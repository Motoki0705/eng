## 🎯 重要な語句・表現

### 1. 冒頭部分（物語への憧れ）

> あづまぢの道のはてよりも、なほ奥つ方に生ひ出でたる人、いかばかりかはあやしかりけむを…

| 語句 | 意味 |
|------|------|
| あづまぢ | 東路（東海道） |
| 道のはて | 道の果て |
| なほ | さらに |
| 奥つ方 | 奥の方（上総国） |
| 生ひ出づ | 成長する |
| いかばかり | どれほど |
| あやし | 田舎びている |

---

### 2. 源氏物語への憧れ

> 源氏の五十余巻、ひつに入りながら得て帰る心地のうれしさぞ、いみじきや。

| 語句 | 意味 |
|------|------|
| 五十余巻 | 五十巻以上 |
| ひつ | 櫃（収納箱） |
| 心地 | 気持ち |
| いみじき | 非常に（良い意味） |

---

### 3. 物語に夢中な様子

> はしるはしる、わづかに見つつ、心も得ず心もとなく思ふ源氏を…

| 語句 | 意味 |
|------|------|
| はしるはしる | 走り読みしながら |
| わづかに | わずかに、少しずつ |
| 心も得ず | 内容を理解できず |
| 心もとなし | じれったい |

---

### 4. 夢のお告げ

> 天照大神を見奉らむと思へ

**ポイント：**
- 物語に夢中な娘への戒めの夢
- 信仰心の重要性を示す

## 📝 練習問題

### 問題1
次の語句の意味を答えよ。

1. あづまぢ
2. 生ひ出づ
3. はしるはしる
4. 心もとなし

### 解答
1. 東路（東海道）
2. 成長する
3. 走り読みしながら
4. じれったい、待ち遠しい

---

### 問題2
作者が強く憧れた物語は何か。

### 解答
**源氏物語**

特に「光る源氏の夕顔」「宇治の大将」（薫）の物語に憧れ、自分もそのようになりたいと願った。
