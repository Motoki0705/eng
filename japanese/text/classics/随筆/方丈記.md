## 🎯 重要な語句・表現

### 1. 冒頭（ゆく川の流れ）

> ゆく川の流れは絶えずして、しかも、もとの水にあらず。よどみに浮かぶうたかたは、かつ消えかつ結びて、久しくとどまりたるためしなし。

| 語句 | 意味 |
|------|------|
| 絶えずして | 絶えることなく |
| しかも | それでいて |
| もとの水 | 元の水 |
| よどみ | 流れが滞る場所 |
| うたかた | 水の泡 |
| かつ～かつ | 一方では～一方では |
| ためし | 例 |

---

### 2. 無常観の表現

> 世の中にある人とすみかと、またかくのごとし。

| 語句 | 意味 |
|------|------|
| 世の中にある | この世に存在する |
| すみか | 住居 |
| かくのごとし | このようである |

**ポイント：**
- 川の流れと人の世を対比
- 人も家も変わりゆくもの

## 📝 練習問題

### 問題1
次の語句の意味を答えよ。

1. 絶えずして
2. うたかた
3. かつ～かつ
4. ためし

### 解答
1. 絶えることなく
2. 水の泡
3. 一方では～一方では
4. 例

---

### 問題2
冒頭で比喩として使われているものを答えよ。

### 解答
**川の流れ**と**水の泡（うたかた）**

川の流れ：絶えず流れ、同じ水はとどまらない
→ 人の世の無常を象徴
