## 📖 構成と特徴

### 三種類の段

| 種類 | 内容 | 例 |
|------|------|---|
| **類聚段** | 「〜は」で始まるリスト | 「山は」「木の花は」 |
| **随想段** | 折々の感想 | 「春はあけぼの」 |
| **日記段** | 宮中での出来事 | 中宮定子との日々 |

### 特徴
- 知性と機知に富む
- 「をかし」の美意識
- 宮中生活への憧れ

## 🎯 重要な語句・表現

### 1. 冒頭（春はあけぼの）

> 春はあけぼの。やうやう白くなりゆく山ぎは、すこしあかりて、紫だちたる雲の細くたなびきたる。

| 語句 | 意味 |
|------|------|
| あけぼの | 夜明け、明け方 |
| やうやう | だんだん |
| 山ぎは | 山の稜線 |
| あかりて | 明るくなって |
| 紫だちたる | 紫がかった |
| たなびきたる | たなびいている |

---

### 2. 四季のよさ

| 季節 | 良い時間帯 | 風情 |
|------|-----------|------|
| **春** | あけぼの | 紫だちたる雲 |
| **夏** | 夜 | 蛍、雨の音 |
| **秋** | 夕暮れ | 烏、雁 |
| **冬** | 早朝 | 雪、炭火 |

---

### 3. 「をかし」の美意識

> いと**をかし**。

| 語句 | 意味 |
|------|------|
| をかし | 趣がある、興味深い、面白い |

清少納言の美意識を表す中心語。
⇔ 紫式部の「あはれ」

---

### 4. 雪のいと高う降りたるを

> 「少納言よ、香炉峰の雪いかならむ。」と仰せらるれば、御格子上げさせて、御簾を高く上げたれば、笑はせ給ふ。

| 語句 | 意味 |
|------|------|
| 香炉峰 | 中国の山（白居易の詩に登場） |
| 御格子 | 格子戸 |
| 御簾 | すだれ |
| 笑はせ給ふ | お笑いになる |

**ポイント：**
- 白居易の詩「香炉峰下新ト山居草堂初成 偶題東壁」の引用
- 「簾をかかげて見る」という詩の一節を実行

## 📝 練習問題

### 問題1
次の語句の意味を答えよ。

1. あけぼの
2. やうやう
3. 紫だちたる
4. をかし

### 解答
1. 夜明け、明け方
2. だんだん
3. 紫がかった
4. 趣がある、興味深い

---

### 問題2
四季それぞれの「よい時間帯」を答えよ。

### 解答
1. 春：**あけぼの**（明け方）
2. 夏：**夜**
3. 秋：**夕暮れ**
4. 冬：**早朝**（つとめて）
