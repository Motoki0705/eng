## 🎯 重要な語句・表現

### 1. 序段（冒頭）

> つれづれなるままに、日暮らし硯にむかひて、心にうつりゆくよしなしごとを、そこはかとなく書きつくれば、あやしうこそものぐるほしけれ。

| 語句 | 意味 |
|------|------|
| つれづれなる | することがなく退屈な |
| ままに | まかせて |
| 日暮らし | 一日中 |
| よしなしごと | とりとめのないこと |
| そこはかとなく | なんとなく |
| あやしう | 不思議と |
| ものぐるほし | 狂おしい、気がおかしくなりそうだ |

---

### 2. 第七段（あだし野の露）

> あだし野の露消ゆるときなく、鳥部山の煙立ち去らでのみ住み果つる習ひならば…

| 語句 | 意味 |
|------|------|
| あだし野 | 京都の墓地 |
| 鳥部山 | 京都の火葬場 |
| 住み果つる | 住み続ける |
| 習ひ | ならわし |

**ポイント：**
- 人の命のはかなさを説く
- 「無常」の思想

---

### 3. 第五十二段（仁和寺にある法師）

> 仁和寺にある法師、年寄るまで石清水を拝まざりければ…

| 語句 | 意味 |
|------|------|
| 年寄る | 年を取る |
| 拝まざりければ | 参拝しなかったので |

**教訓：**
「先達はあらまほしきことなり」
→ 何事にも案内者は必要である

---

### 4. 第百三十七段（花は盛りに）

> 花は盛りに、月は隈なきをのみ見るものかは。

| 語句 | 意味 |
|------|------|
| 盛りに | 満開の時に |
| 隈なき | 曇りのない |
| ものかは | ～だろうか（いや、そうではない） |

**ポイント：**
- 反語表現
- 不完全な美の価値を説く

## 📝 練習問題

### 問題1
次の語句の意味を答えよ。

1. つれづれなる
2. よしなしごと
3. ものぐるほし
4. 先達

### 解答
1. することがなく退屈な
2. とりとめのないこと
3. 気がおかしくなりそうだ
4. 案内者、先輩

---

### 問題2
次の文の意味を答えよ。

> 花は盛りに、月は隈なきをのみ見るものかは。

### 解答
花は満開の時だけ、月は曇りのない時だけを見るものだろうか（いや、そうではない）。
→ 不完全なものにこそ趣がある
