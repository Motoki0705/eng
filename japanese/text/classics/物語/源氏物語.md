## 🎯 重要な語句・表現

### 1. 桐壺巻（冒頭）

> いづれの御時にか、女御・更衣あまたさぶらひ給ひけるなかに、いとやむごとなき際にはあらぬが、すぐれて時めき給ふありけり。

| 語句 | 意味 |
|------|------|
| いづれの御時 | どの帝の御代 |
| 女御・更衣 | 帝の后・側室 |
| さぶらふ | お仕えする（謙譲語） |
| やむごとなき | 高貴な |
| 際 | 身分 |
| 時めく | 寵愛を受ける |

---

### 2. 敬語表現

源氏物語は**敬語の宝庫**。

| 敬語 | 種類 | 対象 |
|------|------|------|
| 給ふ（四段） | 尊敬語 | 高貴な人物 |
| 給ふ（下二段） | 謙譲語 | 補助動詞 |
| おはす | 尊敬語 | 「いる」「行く」 |
| まゐる | 謙譲語 | 「参上する」 |
| 聞こゆ | 謙譲語 | 「申し上げる」 |

---

### 3. 重要助動詞

> すぐれて時めき**給ふ**ありけり。

| 助動詞 | 意味 |
|--------|------|
| 給ふ | 尊敬（～なさる） |
| けり | 過去（～た） |

---

### 4. 「やむごとなし」の識別

> いと**やむごとなき**際にはあらぬが

**ポイント：**
- 「やむごとなし」＝高貴だ、格別だ
- 「やむごとなき際にはあらぬ」＝高貴な身分ではない

## 📝 練習問題

### 問題1
次の敬語の種類を答えよ。

1. さぶらひ**給ひ**ける
2. **まゐり**給ふ
3. **聞こえ**給ふ
4. **おはします**

### 解答
1. 尊敬語（四段活用「給ふ」）
2. 謙譲語（参上する）＋尊敬語
3. 謙譲語（申し上げる）＋尊敬語
4. 尊敬語（いらっしゃる）

---

### 問題2
次の語句の意味を答えよ。

1. やむごとなし
2. 時めく
3. 際
4. さぶらふ

### 解答
1. 高貴だ、格別だ
2. 帝の寵愛を受ける
3. 身分
4. お仕えする

## 💡 福岡大学での出題ポイント

### 出題傾向
- 桐壺巻・若紫巻からの出題が多い
- 敬語の識別（二重敬語）
- 助動詞「む」「べし」の意味

### 頻出ポイント
1. 冒頭文の読解
2. 「給ふ」の識別（四段・下二段）
3. 敬語から主語を特定
4. 「やむごとなし」「時めく」などの重要語
