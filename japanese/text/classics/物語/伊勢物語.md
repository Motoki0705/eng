## 🎯 重要な語句・表現

### 1. 初段（初冠）

> 昔、男、初冠して、平城の京、春日の里にしるよしして、狩に往にけり。

| 語句 | 意味 |
|------|------|
| 初冠 | 元服（成人の儀式） |
| 平城の京 | 奈良 |
| しるよし | 領地を持つ縁 |
| 往にけり | 行った |

---

### 2. 第九段（東下り）

> 昔、男ありけり。その男、身をえうなきものに思ひなして、京にはあらじ、東の方に住むべき国求めにとて行きけり。

| 語句 | 意味 |
|------|------|
| えうなし | 用なし→無用だ |
| あらじ | いるまい（打消推量） |
| 住むべき | 住むのにふさわしい |

---

### 3. 有名な和歌

#### 東下り（第九段）
> **から衣 きつつなれにし つましあれば はるばるきぬる 旅をしぞ思ふ**

| 掛詞 | 意味① | 意味② |
|------|-------|-------|
| きつつ | 着つつ | 来つつ |
| なれ | 慣れ | 萎れ |
| つま | 褄（着物の端） | 妻 |
| はる | 張る | 遥々 |
| きぬる | 着ぬる | 来ぬる |

「かきつばた」の五文字を**折句**として詠み込んでいる。

---

### 4. 筒井筒（第二十三段）

> **筒井つの 井筒にかけし まろがたけ 過ぎにけらしな 妹見ざるまに**

幼なじみとの再会を詠んだ歌。

## 📝 練習問題

### 問題1
次の語句の意味を答えよ。

1. 初冠
2. えうなし
3. 住むべき国
4. 東下り

### 解答
1. 元服（成人の儀式）
2. 無用だ、役に立たない
3. 住むのにふさわしい国
4. 都から東国へ下ること

---

### 問題2
次の和歌の掛詞を指摘せよ。

> から衣 きつつなれにし つましあれば はるばるきぬる 旅をしぞ思ふ

### 解答
1. **きつつ**：着つつ / 来つつ
2. **なれ**：慣れ / 萎れ
3. **つま**：褄 / 妻
4. **はる**：張る / 遥々
5. **きぬる**：着ぬる / 来ぬる

## 💡 福岡大学での出題ポイント

### 出題傾向
- 東下り・筒井筒からの出題が多い

- 助動詞「けり」「べし」の識別

### 頻出ポイント
1. 「昔、男ありけり」の構文
2. 掛詞の識別と解釈
3. 「えうなし」「あらじ」などの重要語
4. 助動詞「じ」（打消推量）の識別
