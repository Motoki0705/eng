## 🎯 重要な語句・表現

### 1. 序章（月日は百代の過客）

> 月日は百代の過客にして、行きかふ年もまた旅人なり。

| 語句 | 意味 |
|------|------|
| 百代 | 永遠 |
| 過客 | 旅人 |
| 行きかふ年 | 過ぎゆく年月 |
| 旅人なり | 旅人である |

**ポイント：**
- 李白「春夜宴桃李園序」の引用
- 人生を旅に例える

---

### 2. 旅立ち

> 草の戸も住み替はる代ぞ雛の家

| 語句 | 意味 |
|------|------|
| 草の戸 | 粗末な家 |
| 住み替はる | 住人が替わる |
| 代 | 時代 |
| 雛の家 | ひな人形を飾る家 |

---

### 3. 平泉（夏草や）

> **夏草や 兵どもが 夢の跡**

| 語句 | 意味 |
|------|------|
| 兵ども | 武士たち（奥州藤原氏） |
| 夢の跡 | 儚い夢の名残 |

**背景：**
- 奥州藤原氏の栄華と滅亡
- 源義経の最期
- 無常観を表現

---

### 4. 立石寺（閑かさや）

> **閑かさや 岩にしみ入る 蝉の声**

| 語句 | 意味 |
|------|------|
| 閑かさ | 静けさ |
| 岩にしみ入る | 岩に染み込んでいくような |

## 📝 練習問題

### 問題1
次の語句の意味を答えよ。

1. 百代の過客
2. 草の戸
3. 兵ども
4. 夢の跡

### 解答
1. 永遠の旅人
2. 粗末な家
3. 武士たち
4. 儚い夢の名残

---

### 問題2
次の俳句が詠まれた場所を答えよ。

1. 夏草や兵どもが夢の跡
2. 閑かさや岩にしみ入る蝉の声
3. 五月雨をあつめて早し最上川

### 解答
1. **平泉**（岩手県）
2. **立石寺**（山形県）
3. **最上川**（山形県）
