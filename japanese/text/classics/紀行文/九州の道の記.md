# 九州の道の記

## 📌 基本情報

| 項目 | 内容 |
|------|------|
| **成立** | 江戸時代前期（1665年） |
| **作者** | 北村季吟（きたむらきぎん） |
| **ジャンル** | 紀行文 |
| **内容** | 江戸から九州への旅 |
| **特徴** | 福岡大学で出題された作品 |

---

## 📖 内容と特徴

### 旅程
- 江戸を出発
- 東海道・山陽道を西へ
- 九州各地を巡る
- 福岡にも言及

### 著者について
- 北村季吟は江戸時代の国学者・歌人
- 松尾芭蕉の師匠
- 『源氏物語湖月抄』の著者

### 特徴
- 各地の名所・旧跡を詠む
- 和歌が多数収録
- 平明な文体

---

## 🎯 重要な語句・表現

### 1. 旅立ちの描写

| 語句 | 意味 |
|------|------|
| 立ちいづ | 出発する |
| 名残惜し | 別れがたい |
| 旅心地 | 旅の気分 |
| 道すがら | 道中 |

---

### 2. 紀行文の定型表現

| 表現 | 意味 |
|------|------|
| ○○を過ぎて | ○○を通り過ぎて |
| ○○に着きぬ | ○○に到着した |
| ○○といふ所 | ○○という場所 |
| ○○を眺む | ○○を眺める |

---

### 3. 九州の名所

| 地名 | 現在地 |
|------|--------|
| 筑紫 | 福岡県 |
| 博多 | 福岡市 |
| 太宰府 | 太宰府市 |

### 4. 歌枕と和歌

> 筑紫なる 香椎の宮の 綾杉は…

**ポイント：**
- 香椎宮（福岡市）は歌枕
- 万葉集以来の伝統

## 📝 練習問題

### 問題1
次の語句の意味を答えよ。

1. 立ちいづ
2. 名残惜し
3. 道すがら
4. 眺む

### 解答
1. 出発する
2. 別れがたい、心残りだ
3. 道中、途中
4. 眺める

---

### 問題2
「九州の道の記」の作者と時代を答えよ。

### 解答
- **作者**：北村季吟
- **時代**：江戸時代前期（1665年）

## 💡 福岡大学での出題ポイント

### 出題傾向
- **2020年（問題2-11）** で出題
- 地名・名所の読み取り
- 紀行文特有の表現

### 頻出ポイント
1. 「立ちいづ」「道すがら」などの旅の表現
2. 助動詞「ぬ」（完了）の識別
3. 九州の地名・歌枕の知識
4. 和歌の解釈
