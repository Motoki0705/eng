# 東関紀行

## 📌 基本情報

| 項目 | 内容 |
|------|------|
| **成立** | 鎌倉時代前期（1242年頃） |
| **作者** | 未詳（源光行説あり） |
| **ジャンル** | 紀行文 |
| **内容** | 京都から鎌倉への旅 |
| **特徴** | 鎌倉時代の代表的紀行文 |

---

## 📖 内容と特徴

### 旅程
- 京都を出発
- 東海道を東へ
- 鎌倉に到着

### 特徴
- 各地の名所・旧跡を詠む
- 和歌と紀行文が融合
- 仏教的無常観

## 🎯 重要な語句・表現

### 1. 東海道の名所

| 地名 | 現在地 | 歌枕 |
|------|--------|------|
| 逢坂の関 | 滋賀県 | これやこの行くも帰るも |
| 美濃 | 岐阜県 | 不破の関 |
| 三河 | 愛知県 | 八橋 |
| 駿河 | 静岡県 | 富士山 |
| 相模 | 神奈川県 | 箱根 |
| 鎌倉 | 神奈川県 | 終着地 |

### 2. 旅の表現

| 語句 | 意味 |
|------|------|
| 旅立つ | 旅に出る |
| 道行き | 旅の途中 |
| 宿る | 泊まる |
| 里 | 村落 |
| 関 | 関所 |

---

### 3. 歌枕の例

#### 八橋（三河）

> 唐衣 きつつなれにし つましあれば はるばるきぬる 旅をしぞ思ふ

『伊勢物語』第九段で詠まれた場所。

#### 富士山（駿河）

> 時知らぬ 山は富士の嶺 いつとてか 鹿の子まだらに 雪の降るらむ

『古今和歌集』の歌。

---

### 4. 無常観

> 世の中の定めなきことを思へば…

| 語句 | 意味 |
|------|------|
| 定めなき | 定まりのない |
| 思へば | 思うと |
| はかなし | 儚い |

## 📝 練習問題

### 問題1
次の地名の現在地を答えよ。

1. 逢坂の関
2. 八橋
3. 不破の関
4. 鎌倉

### 解答
1. 滋賀県（大津市）
2. 愛知県（知立市）
3. 岐阜県（関ケ原町）
4. 神奈川県

---

### 問題2
次の語句の意味を答えよ。

1. 道行き
2. 宿る
3. 関
4. 定めなき

### 解答
1. 旅の途中
2. 泊まる
3. 関所
4. 定まりのない、不安定な
