# 助動詞「む」の識別 - 知識まとめ

## 📌 基本情報

| 項目 | 内容 |
|------|------|
| **接続** | 未然形 |
| **活用型** | 四段型（○・○・む・む・め・○） |
| **意味** | 推量・意志・勧誘・仮定・婉曲 |

---

## 🎯 5つの意味と識別法

### 1. 推量「～だろう」
**条件**: 主語が**三人称**（他人・物事）

> 雨降ら**む**。
> （雨が降る**だろう**。）

---

### 2. 意志「～しよう」
**条件**: 主語が**一人称**（自分）

> 我行か**む**。
> （私は行**こう**。）

---

### 3. 勧誘「～しませんか」
**条件**: 主語が**一人称複数**または**相手を誘う文脈**

> いざ行か**む**。
> （さあ行き**ましょう**。）

---

### 4. 仮定「～としたら」
**条件**: 「む」が**連体形**で、後に体言が続く

> 行か**む**人（行く**としたら**その人）
> 雨降ら**む**日（雨が降る**ような**日）

---

### 5. 婉曲「～ような」
**条件**: 「む」が**連体形**で終わり、断定を避ける

> 言は**む**やうもなし。
> （言う**ような**方法もない。）

---

## 📊 識別フローチャート

```
「む」の識別
    │
    ├─ 主語は一人称？
    │   ├─ Yes → 意志「～しよう」
    │   └─ No → 次へ
    │
    ├─ 主語は三人称？
    │   ├─ Yes → 推量「～だろう」
    │   └─ No → 次へ
    │
    ├─ 「む」の後に体言？
    │   ├─ Yes → 仮定「～としたら」
    │   └─ No → 次へ
    │
    └─ 連体形で終わる？
        ├─ Yes → 婉曲「～ような」
        └─ No → 文脈で判断
```

---

## 💡 覚え方のコツ

### 人称で判断
| 人称 | 意味 |
|------|------|
| 一人称（我・われら） | 意志・勧誘 |
| 二人称（汝・君） | 勧誘・推量 |
| 三人称（彼・人・物） | 推量 |

### 形で判断
| 形 | 意味 |
|----|------|
| 終止形「む」で文が終わる | 推量・意志 |
| 連体形「む」＋体言 | 仮定 |
| 連体形「む」で文が終わる | 婉曲 |

---

## 📝 練習のポイント

1. まず**主語を特定**する
2. 主語が省略されていたら**敬語から推測**
3. 「む」の後に何が続くかを確認
4. 選択肢の訳を当てはめて自然かどうか確認
