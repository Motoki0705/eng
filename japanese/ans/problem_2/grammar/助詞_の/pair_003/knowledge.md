# 格助詞「の」の識別 - 知識まとめ（総合）

## 📌 このpairのテーマ

「の」の5つの用法の**総合問題**です。

---

## 🎯 「の」5つの用法 総復習

| 用法 | 置き換え | 例 | 見分け方 |
|------|---------|-----|---------|
| 連体修飾 | ─ | 父の本 | 所有・所属 |
| 主格 | が | 花の咲く | 「の」＋用言 |
| 同格 | で | 男の若き | 前後が同一 |
| 準体助詞 | もの・こと | 見るの | 「の」が主語・目的語 |
| 比喩 | のような | 玉のごとき | たとえ |

---

## 📊 識別フローチャート

```
「の」の識別
  │
  ├─「ごとし」「やうに」と共起？
  │    └─ YES → 比喩
  │
  ├─「の」＋用言で終わる？
  │    ├─「の」を「が」に置き換え可能？
  │    │    └─ YES → 主格
  │    └─ 前後が同一を指す？
  │         └─ YES → 同格
  │
  ├─「の」が文の主語・目的語？
  │    └─ YES → 準体助詞
  │
  └─ 上記以外
       └─ 連体修飾
```

---

## ⚠️ 紛らわしいパターン

### 主格 vs 同格
| パターン | 用法 | 例 |
|---------|------|-----|
| 体言＋の＋用言 | 主格 | 花の咲く |
| 体言＋の＋連体形（＋体言省略） | 同格 | 男の若き |

### 主格 vs 比喩
- 「雪の降る」→ 雪が降る（主格）
- 「雪の降るやうに」→ 雪のように（比喩）
