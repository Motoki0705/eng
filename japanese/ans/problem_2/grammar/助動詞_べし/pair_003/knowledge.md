# 助動詞「べし」の識別 - 知識まとめ（総合）

## 📌 このpairのテーマ

「べし」6つの意味の**総合問題**です。すべてを識別できるか確認しましょう。

---

## 🎯 「べし」6つの意味 復習

| 意味 | 訳 | キーワード |
|------|-----|-----------|
| **推**量 | ～だろう | 三人称・自然現象・未来 |
| **意**志 | ～しよう | 一人称・決意 |
| **可**能 | ～できる | 否定文・いかで～べき |
| **当**然 | ～すべきだ・～はずだ | 義務・道徳・必然 |
| **命**令 | ～せよ | 二人称・べからず |
| **適**当 | ～するのがよい | まづ・提案 |

---

## 📊 識別フローチャート（完全版）

```
「べし」
  │
  ├─ 否定表現と共起？
  │    ├─ 「べからず」→ 命令（禁止）
  │    └─ 「べきにあらず」「べくもなし」→ 可能
  │
  ├─ 主語は一人称か？
  │    └─ YES ＋ 決意 → 意志
  │
  ├─ 主語は二人称か？
  │    └─ YES ＋ 指示 → 命令
  │
  ├─ 義務・道徳・予定か？
  │    └─ YES → 当然
  │
  ├─ 「まづ」等＋提案か？
  │    └─ YES → 適当
  │
  └─ 上記以外 → 推量
```

---

## ⚠️ 紛らわしいパターン

### 「必ず～べし」の識別
| 主語 | 意味 | 例 |
|------|------|-----|
| 一人称 | 意志 | 我、必ず勝つべし |
| 三人称 | 当然 | 報い、必ず来たるべし |

### 「～べき」＋体言の識別
| パターン | 意味 | 例 |
|---------|------|-----|
| ～べき日 | 当然 | 参るべき日 |
| ～べきやう | 可能 | 言ふべきやうもなし |
| ～べきほど | 推量 | 月の出づべきほど |

---

## 💡 「む」と「べし」の違い

| 助動詞 | 確信度 | 例 |
|--------|--------|-----|
| む | 低い | 雨降らむ（降るかもしれない） |
| べし | 高い | 雨降るべし（きっと降る） |
