# 助動詞「べし」の識別 - 知識まとめ（すいかとめて）

## 📌 このpairのテーマ

助動詞「べし」の6つの意味と識別法を学びます。

---

## 🎯 「べし」6つの意味「すいかとめて」

| 頭文字 | 意味 | 訳 |
|--------|------|-----|
| **す** | 推量 | ～だろう |
| **い** | 意志 | ～しよう |
| **か** | 可能 | ～できる |
| **と** | 当然・義務 | ～すべきだ・～はずだ |
| **め** | 命令 | ～せよ |
| **て** | 適当 | ～するのがよい |

---

## 📊 識別フローチャート

```
「べし」
  │
  ├─ 文脈から「当然・義務」か？
  │    └─ YES → 当然「～すべきだ」「～はずだ」
  │
  ├─ 文脈から「可能」か？
  │    └─ YES → 可能「～できる」
  │
  ├─ 主語は一人称か？
  │    ├─ YES → 意志「～しよう」
  │    └─ NO（二人称） → 命令「～せよ」
  │
  ├─ 提案・助言の文脈か？
  │    └─ YES → 適当「～するのがよい」
  │
  └─ 上記以外 → 推量「～だろう」
```

---

## 🔑 頻出パターン

### 当然・義務（最頻出）
> 人は善を行ふ**べし**。（人は善を行うべきだ）
> 必ず来た**べし**。（必ず来たはずだ）

### 可能
> かかる事の知ら**るべき**にあらず。（～知ることができるはずがない）
> 言ふ**べき**やうもなし。（言いようもない＝言えない）

### 意志（一人称）
> 我、行く**べし**。（私は行こう）
> かならず勝つ**べし**。（必ず勝とう）

### 命令（二人称）
> 汝、慎む**べし**。（おまえは慎め）
> 早く帰る**べし**。（早く帰れ）

### 適当
> 早く起く**べし**。（早く起きるのがよい）
> まづ食ふ**べし**。（まず食べるのがよい）

### 推量
> 雨降る**べし**。（雨が降るだろう）
> 明日は晴る**べし**。（明日は晴れるだろう）

---

## ⚠️ 「む」との違い

| 助動詞 | 確信度 | ニュアンス |
|--------|--------|-----------|
| む | 低い | 推測、可能性 |
| べし | 高い | 確信、必然性 |
