## 学習ワークフロー

福岡大学の古文対策は、以下のワークフローで進めます。

### 📖 読解問題の場合

```
1. ans/{作品名}/pair_XXX/story.md を読む
   → 古文の内容を「わかりやすく・面白く」解説
   → 登場人物、場面設定、あらすじを把握
   
2. tests/reading/{作品名}/pair_XXX/A.md を解く
   → 現代語訳、内容理解の問題に挑戦
   
3. ans/reading/{作品名}/pair_XXX/A.md で答え合わせ
   → 解答と詳細解説を確認
   
4. B.md, C.md... で反復練習
```

### 📝 文法問題の場合

```
1. ans/grammar/{分野名}/pair_XXX/knowledge.md を読む
   → 助動詞・助詞・敬語の知識を確認
   
2. tests/grammar/{分野名}/pair_XXX/A.md を解く
   → 文法問題に挑戦
   
3. ans/grammar/{分野名}/pair_XXX/A.md で答え合わせ
```

### 📚 重要古語の場合

```
1. ans/vocabulary/{分野名}/pair_XXX/knowledge.md を読む
   → 古語の意味と例文を確認
   
2. tests/vocabulary/{分野名}/pair_XXX/A.md を解く
   → 古語の意味を問う問題に挑戦
   
3. ans/vocabulary/{分野名}/pair_XXX/A.md で答え合わせ
```

## 基本方針とルール

### 問題作成の原則

1. **過去問準拠**：福岡大学の出題形式を忠実に再現
2. **段階的学習**：
   - 読解：物語の内容を理解 → 文法・語彙の確認 → 問題演習
   - 文法：知識の確認 → 問題演習 → 読解への応用
3. **解説重視**：
   - `story.md` では古文を「現代のドラマ」のようにわかりやすく解説
   - 単なる現代語訳ではなく、「なぜそうなるのか」を説明

### 命名規則

```
tests/problem_2/
├── reading/                    # 読解問題
│   └── 竹取物語_燕の子安貝/    # {作品名}_{エピソード名}/
│       └── pair_001/
├── grammar/                    # 文法問題
│   └── 助動詞_む/              # {分野}_{テーマ}/
│       └── pair_001/
└── vocabulary/                 # 重要古語問題
    └── 心情語/                 # {カテゴリ}/
        └── pair_001/
```

### pairの定義

- **同じpair内**：同じ知識・同じ古文を使った問題のバリエーション
- **異なるpair**：異なる知識・異なる古文を使った問題セット

## まとめ

### この計画書の使い方

1. **学習開始時**：`story.md` または `knowledge.md` で知識を確認
2. **演習時**：`tests/` で問題を解く
3. **復習時**：`ans/` で解説を読み、理解を深める

### 優先順位

1. **最優先**：助動詞の意味識別（毎回出題）
2. **重要**：敬語と主語の特定（読解の基盤）
3. **重要**：重要古語（単語力＝得点力）
4. **必要**：様々なジャンルの古文に触れる
