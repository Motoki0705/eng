# 大問〔Ⅱ〕古文問題の傾向と対策

## 1. 出題分析：何が問われているか

### 出題形式
福岡大学の古文問題は、**長文読解形式**で出題され、以下のような設問が組み合わされます。

- **文法問題**：助動詞・助詞の意味識別、活用形
- **現代語訳**：傍線部の正確な訳
- **内容理解**：主語の特定、心情把握、内容合致
- **重要古語**：語句の意味を問う問題
- **文学史**：作品のジャンル、成立時代、作者

|--------|------|----------|------|

## 2. 分野別重点学習ポイント

### 【最重要】文法（助動詞・助詞・敬語）

#### ① 助動詞の意味識別（頻出）

| 助動詞 | 意味 | 識別ポイント |
|--------|------|-------------|
| **む** | 推量・意志・勧誘・仮定・婉曲 | 主語の人称、文脈で判断 |
| **ぬ** | 完了・強意 | 「てしまう」「きっと～」の意味 |
| **なり** | 断定・伝聞推定 | 「なり」の接続で判断（体言＝断定、連体形＝伝聞） |
| **り** | 完了・存続 | 四段の已然形、サ変の未然形に接続 |
| **まじ** | 打消推量・打消意志・不適当 | 「む」の打消版 |
| **べし** | 推量・意志・可能・当然・命令・適当 | 文脈で6つの意味を判断 |
| **らむ** | 現在推量・原因推量 | 目の前にないことへの推量 |
| **けむ** | 過去推量・原因推量 | 過去のことへの推量 |

#### ② 助詞の識別

| 助詞 | 用法 | 例文 |
|------|------|------|
| **の** | 主格「～が」 | 花の咲く（花が咲く） |
| **の** | 同格「～で、～である」 | 白き鳥の嘴と脚と赤き（白い鳥で、くちばしと脚が赤い） |
| **ば** | 已然形＋ば＝確定条件 | 見れば（見ると/見たので） |
| **ば** | 未然形＋ば＝仮定条件 | 見ば（見たならば） |
| **に** | 格助詞・接続助詞・断定の連用形 | 文脈で判断 |

#### ③ 敬語と主語の特定

| 敬語の種類 | 敬意の方向 | 例 |
|------------|-----------|-----|
| 尊敬語 | 動作主を高める | おはす、給ふ、のたまふ |
| 謙譲語 | 動作の受け手を高める | 奉る、聞こゆ、参る |
| 丁寧語 | 聞き手を高める | 侍り、候ふ |

**ポイント**：敬語から主語を特定する
- 尊敬語がついている → 身分の高い人が主語
- 謙譲語がついている → 身分の低い人が主語

### 【重要】重要古語

福岡大学で頻出の重要古語：

| 古語 | 意味 | 覚え方 |
|------|------|--------|
| **まめなり** | 誠実だ、まじめだ | 「まめ」に働く＝誠実 |
| **わづらふ** | 悩む、病気になる、苦労する | 「わずらわしい」の語源 |
| **おどろおどろし** | 気味が悪い、大げさだ | 「おどろ」く＋「おどろ」く＝とても恐ろしい |
| **おほけなし** | 身の程知らずだ、恐れ多い | 「大＋気なし」＝分不相応 |
| **いぶせし** | 気が晴れない、うっとうしい | 「いぶかしい」＝気になる |
| **あはれなり** | しみじみと趣がある、かわいそうだ | 感動詞「あはれ」から |
| **をかし** | 趣がある、おもしろい、美しい | 『枕草子』の美意識 |
| **めでたし** | すばらしい、立派だ | 「めで」（愛づ）＋「たし」 |
| **やむごとなし** | 高貴だ、格別だ | 「止む事無し」＝やめられない＝格別 |
| **いみじ** | はなはだしい（良くも悪くも） | 程度が激しい |
| **こころづきなし** | 気に入らない | 「心つく」の打消 |
| **なまめかし** | 優美だ、上品だ | 「生めく」＝若々しい |
| **つれなし** | 冷淡だ、平気だ | 「つれ」（連れ）がない |
| **ゆかし** | 見たい、知りたい、心ひかれる | 「行く」＋「し」 |
| **らうたし** | かわいらしい、いとおしい | 「愛」の訓読み |

### 【重要】現代語訳のポイント

#### 直訳の正確さが求められる
福岡大学の訳問題では、**文脈に合っていても文法的に不正確な訳は不正解**になります。

**例**：「ものしげなる」の訳
- ✕「うっとうしい感じ」（意訳しすぎ）
- ○「なんとなく不快な様子である」（直訳）

#### チェックポイント
1. 助動詞の意味は正しいか
2. 敬語は適切に訳されているか
3. 古語の意味は正確か
4. 省略された主語を補っているか

## 3. 設問タイプ別対策

### タイプ1：主語の特定
**問われ方**：「傍線部の主語は誰か」「この動作をしたのは誰か」

**解法**：
1. 敬語の有無をチェック（尊敬語→身分高い人）
2. 接続助詞「て」「ば」で主語が変わることに注意
3. 会話文の前後で話者が変わることに注意

### タイプ2：助動詞の意味識別
**問われ方**：「傍線部の『む』と同じ意味のものを選べ」

**解法**：
1. まず傍線部の「む」の意味を特定
2. 選択肢の「む」も同様に意味を特定
3. 一致するものを選ぶ

### タイプ3：心情把握
**問われ方**：「この時の作者の心情として最も適当なものを選べ」

**解法**：
1. 心情語（形容詞・形容動詞）を探す
2. 心情語がなければ、行動から推測
3. 敬語から人物関係を把握し、文脈を読む

### タイプ4：内容合致
**問われ方**：「本文の内容と合致するものを選べ」

**解法**：
1. 選択肢を本文と照合
2. 「誰が」「何を」「どうした」を正確に確認
3. 微妙な言い換えに注意（主語のすり替えなど）

## 4. まとめ：古文対策の学習法

### 優先順位

1. **最優先**：助動詞の意味と活用（毎回必ず出題）
2. **重要**：敬語と主語の特定（読解の基盤）
3. **重要**：重要古語300語程度（単語帳レベル）
4. **必要**：文学史の基本（主要作品は必須）

### 学習プラン

1. **文法を固める**
   - 助動詞の意味と接続を暗記
   - 助詞の識別問題を演習
   - 敬語の種類と敬意の方向を整理

2. **古語を覚える**
   - 重要古語を毎日10語ずつ
   - 意味だけでなく、例文で覚える

3. **読解演習**
   - 様々なジャンルの古文を読む
   - 主語を補いながら読む練習
   - 現代語訳を自分で作成してみる

4. **文学史の整理**
   - ジャンル別に整理
   - 成立順に並べられるように

### 総評
福岡大学の古文は、**奇問・難問がなく、基礎をどれだけ正確に固めているかが得点に直結**します。教科書レベルの文法・単語を徹底的に固めることが合格への鍵です。
